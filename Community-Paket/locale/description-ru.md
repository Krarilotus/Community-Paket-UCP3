# Набор сообщества

Набор сообщества включает одни из лучших ИИ, созданных опытными и известными моддерами сообщества Stronghold. Их отличает высокое качество: полностью переработанные персонажи, продуманный порядок строительства и сочетание силы с индивидуальностью, органично вписывающееся в средневековый мир Stronghold Crusader. Они особенно подходят для боёв между ИИ и представляют честный вызов игрокам.

Набором сообщества управляю я, Nevikov.

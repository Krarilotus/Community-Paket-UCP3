# 社区整合包

社区整合包精选了 Stronghold 社区资深知名 AI 模组作者的优秀作品。所有 AI 都具有高质量：全面重塑的角色、精心设计的建造顺序，以及实力与个性的平衡，融入 Stronghold Crusader 的中世纪世界。它们尤其适合 AI 对战，也能为玩家提供公平的挑战。

社区整合包由我（Nevikov）维护。
